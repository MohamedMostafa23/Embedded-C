# SW_for_HW_Interfacing

Cairo University hardware-interfacing labs and a final ADC project for STM32. Start with the [ADC application](ADC-Final-Project/src/main.c) and [Proteus simulation](ADC-Final-Project/Proteus%20Simulation/ADC-Simulation.pdsprj) for a complete example within this lab collection.

For the separately documented ADC driver and temperature-display project, see [Embedded C with STM32](https://github.com/MohamedMostafa23/Embedded-C-with-STM32/tree/main/ADC-Driver-main).

#### This repository contains all labs and tasks submissions codes required in Software For Hardware Interfacing course - Cairo University.

- **tools**:
  - STM32F401CC ARM Microcontroller
  - Proteus 8 Professional v8.12
  - An IDE that supports stm32
  - C-programming language

#### In order to run the projects yourself:

- Generate the _.hex_ file and run it on the proteus simulation.
